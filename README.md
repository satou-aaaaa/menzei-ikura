# おみやげ免税いくら？（menzei-ikura）

海外旅行から帰るときの荷物（酒類・たばこ・香水・その他の品物）を見て、免税になるかを当てる1日5問の学習ゲーム。正解したら、どの決まりの問題かも選ぶ。免税範囲の数や、海外市価・別送品などのしくみの問題も出る。

遊ぶ: <https://satou-aaaaa.github.io/menzei-ikura/>

- 中身は税関「海外旅行者の免税範囲」<https://www.customs.go.jp/kaigairyoko/menzei.htm> に書いてあることだけです。
- 問題に出る旅行や荷物は練習のための例です。税金の額の計算はしません。
- このゲームは税関の判断や、公式の情報の代わりではありません。実際の旅行では、税関のページで確かめてください。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。
